# Atividade 1 - GitHub API

Consulta informações básicas de um usuário GitHub.

## 📋 Descrição

Este script extrai informações básicas do usuário GitHub **Upsetjojos2** utilizando a API REST do GitHub.

## 🚀 Como Executar

### Pré-requisitos
- Python 3.7+
- Biblioteca `requests`

### Instalação

```bash
pip install requests
```

### Executar

```bash
python Atividade.py
```

## 📊 Dados Extraídos

O script exibe:
- Nome do usuário
- Login
- Número de repositórios públicos
- Data de criação da conta
